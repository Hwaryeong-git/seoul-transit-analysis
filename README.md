
# seoul-transit-analysis

서울시 행사 전후 종합운동장역 지하철 이용량 분석

**Python, pandas, Matplotlib, Tableau | Team Project**  
**2026.07 - 2026.08**

대규모 행사 전후 종합운동장역의 지하철 수요 변화를 분석해, **추가 수요가 집중되는 시간대와 우선 대응 노선**을 도출한 데이터 분석 프로젝트입니다.

이 저장소에는 팀 통합 분석 노트북이 포함되어 있으며, 아래는 제가 담당한 내용입니다.

## My Role

- 역별, 일별, 시간대별 지하철 승하차 데이터와 혼잡도 데이터 전처리 및 EDA
- 행사 일정과 승하차 데이터를 결합하고, 행사 시작과 종료 시점을 기준으로 상대시간대 생성
- 동일 연도, 요일, 호선, 시간대의 비행사일 평균을 비교 기준(baseline)으로 설정
- 행사 종료 포함 시간대와 종료 후 1시간대의 2호선 및 9호선 승차 증가 규모 비교
- 분석 결과를 바탕으로 우선 대응 노선과 시간대 제안

## Key Findings

비행사일 기준 대비 평균 승차 증가 인원은 다음과 같습니다.

| 노선 | 종료 포함 시간대 | 종료 후 1시간대 |
|---|---:|---:|
| 2호선 | 약 2,381명 | 약 1,408명 |
| 9호선 | 약 85명 | 약 136명 |

- 행사 종료 후 승차 증가 규모는 2호선에서 더 크게 나타나, 2호선을 우선 대응 노선으로 제안했습니다.
- 종료 후 1시간대에도 수요 증가가 이어져, 행사 종료가 포함된 시간대부터 이후 1시간대까지 연속적으로 관리할 필요가 있다고 판단했습니다.
